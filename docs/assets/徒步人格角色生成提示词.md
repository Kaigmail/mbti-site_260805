# 徒步人格角色图生成提示词

## 一、统一设计风格规范
所有角色均遵循以下视觉规则，保证整体风格统一：
- 视觉风格：低多边形（Low Poly）扁平化矢量插画，几何色块拼接构成，无黑色描边，同色系深浅块面表现结构与光影
- 人物造型：3.5头身卡通化全身立绘，姿态舒展有性格指向性，表情精准外化人格特质
- 特质表达：每个角色配备1-2件核心标志性道具，将抽象人格转化为可视化符号
- 色彩规则：人物服饰主色与背景浅色调为同色系呼应，配色明快和谐、对比度适中
- 背景处理：纯净浅色系纯色背景，无多余场景元素，底部带极淡的柔和投影
