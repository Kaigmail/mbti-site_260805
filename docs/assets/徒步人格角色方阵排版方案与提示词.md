# 徒步人格角色方阵排版方案与生成提示词

## 一、整体排版框架
完全对齐参考图的「按行分组、同组同背景」视觉逻辑，采用 **3行×4列** 方阵布局，共12个角色单元：
- 每一行对应1个气质分组，整行填充统一浅色系背景，直观区分组别
- 单个角色单元为上下结构：上方是角色立绘，下方依次为「中文名称+英文标签」
- 每行左上角标注分组名称，风格与参考图统一为简洁无衬线字体

## 四、排版细节规范（对标参考图）
1. **角色统一规范**：所有角色为3.5头身全身立绘，底部对齐，尺寸大小一致
2. **文字样式**：
   - 分组标题：无衬线粗体，使用对应组的主色调，位于每行左上角
   - 角色中文名：无衬线粗体深灰色，居中对齐，在角色正下方
   - 英文标签：无衬线常规体中灰色，居中对齐，在中文名下方
3. **间距规则**：同行角色水平间距均等，行与行靠背景色直接区分，无需额外分割线
4. **光影统一**：所有角色底部带同方向的淡灰色柔和投影，保持立体感一致
