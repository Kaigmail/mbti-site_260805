## 📊 计分方式

每道题你的选择对应维度加1分，最后统计以下15个对立维度的总分，得分高的一侧就是你该维度的倾向。

|  | 极简即自由 / 装满安全感 |  |
| 社交能量 | 孤独充电宝 / 组团氛围灯 | 领队燕 / 跟随鱼 |

### TURBO · 暴走风火轮

- **分享标签**：#油门焊死徒步人

- **关键词**：速度、目标、不回头
- **简短描述**：能用速度解决的路线，绝不多停留一秒。耳机里是电子节拍，心里只有山顶的倒计时。

  2. 同伴停下来拍照，你在旁边内心疯狂抖腿。
- **行动建议**：
  1. 偶尔调成0.5倍速，野草莓可能就在转角。
  2. 设定“强制休息点”，用一杯咖啡的时间看看山。
